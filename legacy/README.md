# Archived legacy assets

This directory contains historical, non-runtime assets retained only for repository
provenance. Nothing under `legacy/` is part of the current package, CLI, public
product route, or evaluator contract.

- `legacy/plutus/` is the former static product-page asset.
- `legacy/contextforge/` is an old generated cache retained for traceability.

The active product surfaces use the canonical names **Perseus Context Engine**,
**Perseus Vault**, and **Perseus Ledger**. The root `vault/` route is intentionally
not archived: it is the current Perseus Vault web/API-reference route.
