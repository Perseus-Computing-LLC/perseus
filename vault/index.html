What changes

Your agent stops starting from zero.

Without durable memory, every session re-derives the same preferences, conventions, failures, and decisions. Vault makes the useful past available without treating every old fact as permanent truth.

  • Remember decisions and corrections
  • Recall by keyword, meaning, and graph
  • Ask what was true at a past point in time
Why it is different

More than a vector store.

Vault gives the memory layer a lifecycle: confidence decay, promotion, history, retention, audit, and explicit deletion. The agent gets continuity; you keep control.

  • Bi-temporal history with valid_at and as_of
  • Hybrid BM25 + dense recall with RRF
  • Encrypted entity bodies and chained journal events
Boundary by design

The memory belongs to the team that created it.

Vault runs locally with no required network, API key, or model download. Use stdio for the default path; add authenticated HTTP/SSE only when your deployment calls for it. Encryption and index posture are documented explicitly.
