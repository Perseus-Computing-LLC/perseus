# Historical benchmark archive

This directory contains research harnesses, fixtures, and reports produced during Perseus Context Engine development. It is not the current public claims surface.

Use these sources before quoting a result:

- [Public methods desk](https://perseus.observer/benchmarks/) for the measurements currently presented by Perseus Computing LLC
- [`claims.json`](../claims.json) for publication status, method, denominator, control, and limitations
- the exact report linked by the applicable claim record

A synthetic scenario is not a customer result, production deployment, cost guarantee, or evidence of Government approval. Files retained here may describe retired methods or claims. A result marked `publishable: false` in `claims.json` must not be reused as marketing copy.
