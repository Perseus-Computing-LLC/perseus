Where it fits

One bounded role beside the mission system.

Perseus provides context, memory, and records. The program and its prime retain the surrounding mission responsibilities.

Current context

Start with the state of the work.

Context Engine builds a briefing from the sources the host chooses.

Durable memory

Carry decisions into the next task.

Vault keeps dated facts, corrections, and choices locally.

Reviewable records

Leave a trail people can check.

Ledger records supplied events and references in a hash chain.
