Security posture

Inspect the data path before you inspect the marketing.

The context engine renders state and the Vault stores memory on infrastructure you control. Ledger provides an evidence surface for consequential events. Each product documents its own boundary so the combined system does not become an unexamined blob.

DeploymentAir-gapped, on-premises, private VPC, or classified environments.
Data at restVault supports AES-256-GCM for entity bodies; index and key handling are explicit.
AccessWorkspace boundary enforcement, explicit shell gates, and bearer-token protection for HTTP/SSE (see Security Model ↗).
OwnershipMIT licensing, local files, plain exports, no mandatory vendor service.
