01 / quality

End-to-end QA: LongMemEval

The headline product-quality result is the mean of three independent full runs using LongMemEval’s official step-by-step CoT answer prompt. The signed distribution is 80.0% / 78.6% / 78.4%, for a 79.0% mean. The plain prompt is a separate 73.8% distribution and remains visible as a methodology distinction — never blended into the CoT claim.

Reproduce

If you cannot rerun the number, do not headline it.

Clone the repository, build the binary, and run the offline suites. The end-to-end QA command names its external key requirement and prints cost before work begins.

perseus-vault benchmarksOPEN / RERUNNABLE
$ git clone https://github.com/Perseus-Computing-LLC/perseus-vault.git
$ cd perseus-vault && cargo build --release
$ python benchmark/longmemeval/run.py
$ python benchmark/temporal/gauntlet.py
$ python benchmark/beam/run.py --tiers 128K 500K 1M 10M
