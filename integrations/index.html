Official LangChain integration

Tools, retrieval, and direct MCP access.

Perseus Vault is listed in the LangChain documentation registry. The Python package langchain-perseus-vault provides an agent toolkit, a BaseRetriever, and a low-level MCP client for a local perseus-vault binary.

Registry listing is an external documentation integration, not an endorsement claim. Source: langchain-ai/docs#4725 ↗, merged July 30, 2026 (00e822f7da2b0d0ba84d5aa81a2bb826d44a0245).
