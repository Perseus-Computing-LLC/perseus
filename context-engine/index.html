The problem

The first turn should not be archaeology.

Without a context layer, an agent spends its opening turns finding the port, re-reading the last checkpoint, checking whether tests are stale, and rediscovering which conventions matter. That is not intelligence; it is repeated setup.

Resolve

Directives read the workspace and produce a bounded, human-readable context file.

Explain

Decisions are rendered with source paths, timestamps, and explicit confidence rather than hidden retrieval.

Watch

Keep the briefing current with a watcher or your existing cron, systemd, or launchd schedule.

Connect

MCP tools work with Claude Code, Cursor, Codex, Hermes, or your own host.

Three commands to a first render

Start local. Keep the control plane yours.

The quickstart detects the stack, scaffolds .perseus/context.md, writes configuration, and verifies the first render. It does not require an account or a hosted service.

first renderNO ACCOUNT REQUIRED
$ pip install perseus-ctx
$ cd your-project && perseus quickstart
$ perseus render .perseus/context.md -o AGENTS.md
Security surface
01 / boundary

Read-only by default

Rendering produces context; it does not silently write to the workspace or persist agent memory.

02 / guardrails

Dangerous directives gated

Shell-executing operations require an explicit opt-in. Workspace and SSRF protections are part of the path.

03 / formats

Plain files, open outputs

Write AGENTS.md, CLAUDE.md, .cursorrules, or another file your assistant already reads.
