What it does

A verifiable record for every consequential event.

Record activity

Each event can carry actor, boundary, configuration, action, result, external evidence, and optional allocation metadata.

Verify the chain

Append-only, hash-chained records support local verification and optional external checkpoints for independent review.

Integrate anywhere

HTTP ingestion, a Python SDK, and optional allocation, reconciliation, and settlement adapters work with any runtime.

One command

Record, link, and verify.

Send events through the stable API or SDK, associate the evidence and authority context you have, then verify the chain. Existing plutus commands remain supported during the transition.

plutus meter
$ plutus meter --provider anthropic --model claude-opus-4-8 \
             --task code_review --input 8200 --output 2400

✓ event recorded   hash-chained
✓ evidence linked   verifiable

dashboard → http://localhost:8420 · local ledger
